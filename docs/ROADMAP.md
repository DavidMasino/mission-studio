# Direction & status

[← Back to Mission Studio](../README.md)

Updated 9 October 2026. This page separates the working local app from ideas that still need design and validation.

## Working in the local app

- Project and cycle planning with permanent mission references.
- Home, weekly plans, mission details and longer-term milestones.
- Saved results, evidence references, reviews, blockers and activity history.
- Assistant proposals and bounded automatic date proposals for owner review.
- Local factual weekly-summary drafts, reviewed before saving.
- Shared UI/command storage with revision checks and recoverable snapshots.
- Light, dark and system appearance with multiple colour themes.

The current implementation is used in the creator's own project workflow. The public repository is a documentation and screenshot preview, with no installable application release.

## Near-term direction

- Learn from people managing real projects with AI assistants.
- Make the next action and daily focus easier to understand.
- Improve onboarding, the guide and the handoff to a project's assistant.
- Continue testing save, conflict and recovery behaviour alongside interface improvements.

## Being explored

- A daily planning view alongside weekly missions.
- A closer fit with Project 000's project setup and review workflow.
- Collaboration with colleagues and easier assistant connections.
- A distribution model: open source, a paid service, or a combination.

These are directions, not committed release dates or enabled features. Remote team accounts, cloud hosting, unattended AI execution and automatic chat synchronization are not available in the current app.
